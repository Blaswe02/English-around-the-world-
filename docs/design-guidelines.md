# English Around the World — visual preferences

Daan's explicit preference, 20 November 2026:
- Do not add decorative pictograms, emoji, generic AI-style icons or stock glyph badges.
- Use real destination photography, typography, colour and whitespace.
- Use text labels for navigation, actions and status. Icon-only controls must have visible text.
- Preserve meaningful visuals such as the geographic globe, maps and classroom artwork.
- Preserve access rules and learning content when changing presentation.
- Destination tiles use locally stored, optimised photographs with a consistent wide crop. Keep photographer and source links in Photo credits.
